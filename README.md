## 🚀 Overview

The **YouTube RAG App** is a fast and user‑friendly AI application that allows users to upload YouTube videos or podcasts and **ask questions about their content**. Instead of watching the full video, users can get **instant summarized insights and answers** directly using AI and RAG (Retrieval‑Augmented Generation) techniques.

This app uses:
- **Streamlit** for an interactive frontend  
- **Groq model** for powerful RAG capabilities  
- **Hugging Face** models to generate embeddings  
- **FAISS** for fast vector similarity search  

Together, these make processing **large videos and podcasts quick and efficient** for users.

---

## ⭐ Features

- 📹 Upload YouTube videos or podcast audio  
- ❓ Ask questions and get instant answers  
- 🧠 Summarize long video content  
- 🚀 Fast retrieval using **FAISS vector store**
- 🖥️ Clean and intuitive **Streamlit UI**
